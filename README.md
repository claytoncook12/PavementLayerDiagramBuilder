# Pavement Layer Diagram Builder

A web-based tool for creating scaled pavement section diagrams.

## Features

- **Layer Types**: Asphalt, Concrete, Aggregate Base, Open Graded Base, Stabilized Base, Sub-Base, Subgrade
- **Scaled Diagrams**: Configurable scale (px per inch) and width
- **Geogrid Support**: Multiple types with color-coded display
- **Infinite Depth**: Option for subgrade layers
- **PNG Export**: High-resolution (4x) export with title
- **Save/Load**: Store diagrams in browser localStorage

## Usage

Open `index.html` in a browser. Add layers, configure settings, and export.

## Files

- `index.html` - Main HTML structure
- `styles.css` - Styling and layer textures
- `app.js` - Application logic
